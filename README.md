# JustDoList

JustDoList est une application web collaborative qui permet à une équipe de gérer son planning, ses tâches, ses disponibilités et ses échanges dans une interface unique.

Projet réalisé dans le cadre du module **Interaction Homme-Machine**, en **Master Informatique à l’Université de Montpellier**, durant l’année universitaire **2025–2026**.

## Objectif

Faciliter la coordination d’un groupe en réunissant les outils utiles au travail collectif, avec des modules que chaque membre peut afficher ou masquer selon ses besoins.

## Fonctionnalités

- **Semainier** : créer des événements et consulter le planning de l’équipe.
- **Taskboard** : suivre les tâches selon leur avancement.
- **Barre Équipe** : visualiser les disponibilités des membres.
- **Messagerie rapide** : échanger avec l’équipe.
- **Coach Assistant** : détecter les conflits de planning et proposer des alternatives.
- **To-Do rapide** : noter les petites actions à réaliser.
- **Boîte à Idées** : partager des idées ou conserver des brouillons privés.
- **Personnalisation** : afficher ou masquer les modules.

## Technologies

- HTML5
- CSS3
- JavaScript natif, sans framework

## Démarche IHM

La conception repose sur une analyse des besoins utilisateurs, un scénario d’utilisation, des maquettes et un storyboard.

Un walkthrough a permis d’identifier des améliorations concernant la lisibilité des champs, la visibilité du bouton de validation et le retour affiché après les actions.
